# Security Policy

## Authorized Use

NetReconX is designed for authorized security assessment,
education, research, and defensive security purposes.

Users must have explicit permission to assess any target
against which NetReconX is operated.

## Responsible Use

Do not use NetReconX to:

- Access systems without authorization
- Evade security controls
- Disrupt services
- Exploit vulnerabilities
- Perform denial-of-service activity
- Collect information beyond the scope of an authorized assessment

## Reporting Security Issues

Security issues affecting the NetReconX project should be
reported privately to the project maintainers rather than
disclosed publicly before remediation.
